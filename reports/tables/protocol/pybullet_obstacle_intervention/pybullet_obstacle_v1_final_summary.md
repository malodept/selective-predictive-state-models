# PyBullet obstacle v1 exact-intervention final summary

## Goal

PyBullet obstacle v1 extends PyBullet v0 by introducing visible obstacles and collisions. The objective is to test whether the exact-intervention protocol remains identifiable and whether solving the task requires both the current state and the action.

Each group is generated by:

```text
save PyBullet simulator state with obstacles
execute action a_1 -> future_1
restore same simulator state
execute action a_2 -> future_2
...

Unlike v0, action effects depend on the obstacle configuration.

Interpretation

The full state-action model strongly outperforms every ablation.

The action-only model remains essentially at chance, so the benchmark is not solved by a global action template. The state-only and no-context models also remain at chance, showing that the future branch cannot be identified without the intervention action.

This validates PyBullet obstacle v1 as a stronger exact-intervention state-action grounding benchmark than v0.

Project-level conclusion

The experimental progression is now:

TartanAir observational silver:
    weak oracle, learned models at chance

Toy exact intervention:
    perfect oracle, perfect learned model

PyBullet exact v0:
    perfect oracle, near-perfect learned model, state-action ablations pass

PyBullet obstacle v1:
    perfect oracle, strong learned model, state-action ablations pass under obstacle-dependent dynamics

This supports the central thesis:

action-grounded future prediction requires identifiable intervention structure;
observational pseudo-counterfactual mining is insufficient, while exact-intervention data makes the problem learnable.
Next step

The current v1 result is strong but based on a 500-group pilot. The next step should be a scale-up and robustness check:

PyBullet obstacle v1 scale:
    2000 groups
    multiple seeds
    full/action-only/state-only/no-context ablations

If the same pattern holds, the project can move to a more realistic exact-intervention simulator such as CALVIN or Habitat.
