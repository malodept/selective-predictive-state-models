## Interpretation

- If oracle gain over best fixed is large, there is real headroom for learned multi-capacity routing.
- If oracle mostly selects one model, fixed capacity is sufficient for that shift.
- If oracle selection is mixed, the shift contains instance-level heterogeneity that a router could exploit.
- The next step should only train a router if this table shows meaningful oracle headroom.
