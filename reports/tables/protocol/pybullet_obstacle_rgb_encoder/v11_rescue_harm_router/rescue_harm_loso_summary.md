# SPSM v11 rescue-harm local router — leave-one-hard-out

This decomposes value-of-computation into local rescue and harm probabilities.
The router estimates `P(full correct, small wrong | x)` and `P(full wrong, small correct | x)`, then routes when predicted rescue outweighs harm and compute cost.

## Interpretation guide

- If rescue-harm beats local expected-gain, decomposing positive and negative transfer matters.
- If routed harm is high, the large model is unsafe in that regime.
- If geometry still loses to context, the current mined geometry features are not the right physical signal.
