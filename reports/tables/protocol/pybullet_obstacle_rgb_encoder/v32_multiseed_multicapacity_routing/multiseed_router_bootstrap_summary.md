## Interpretation

- Stable positive H=48 gains would support a robust learned multi-capacity routing claim.
- H=72 should be treated as a remaining routing-signal problem if oracle headroom is large but learned gains are unstable.
- The ridge expected-utility router is the cleanest pre-specified learned baseline; best-of-method results are useful but should be reported more cautiously.
