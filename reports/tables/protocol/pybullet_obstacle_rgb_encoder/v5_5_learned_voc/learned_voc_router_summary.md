## Interpretation

A useful learned router should approach oracle utility more closely than the confidence-threshold baseline, especially on hard OOD variants. If it improves over always-full at non-trivial cost while keeping high accuracy, this supports the SPSM value-of-computation claim: the system can learn when expensive predictive computation is worth paying for.
