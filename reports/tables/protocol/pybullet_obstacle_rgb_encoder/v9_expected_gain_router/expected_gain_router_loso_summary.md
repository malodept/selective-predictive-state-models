# SPSM v9 expected-gain router — leave-one-hard-out

This evaluates routers that estimate expected value-of-computation gain directly.
Instead of training a separate binary classifier for every lambda, ridge gain models predict `E[full_correct - small_correct | x]` and route when predicted gain exceeds the compute cost.

## Interpretation guide

- If ridge-context beats context-cls, the expected-gain formulation is better than lambda-specific classification.
- If ridge-geometry or tuned-geometry beats ridge-context, local geometry contains useful value-of-computation signal.
- If all learned routers lose to confidence or cheap-only, the current features are not sufficient and we should design physical geometry features directly from the environment.
