# PyBullet exact-intervention v0 summary

## Goal

After validating the protocol on a fully synthetic toy benchmark, PyBullet exact-intervention v0 tests the same idea in a minimal physical simulator.

Each candidate group is generated by:

```text
save PyBullet simulator state
execute action a_1 -> future_1
restore same state
execute action a_2 -> future_2
...

This provides true exact-intervention branches, unlike observational TartanAir silver groups.

Interpretation

The PyBullet exact-intervention benchmark validates the complete action-grounding pipeline in a physical simulator.

The model succeeds only when evaluated with the correct action. Zero and shuffled actions collapse to chance or below chance.

This confirms the core project diagnosis:

observational pseudo-counterfactual groups are not enough;
exact interventions make action-grounded future ranking identifiable and learnable.
Decision

PyBullet v0 is validated.

The next step is not to scale this exact setup blindly, because v0 may still be too easy. The next scientific test should check whether the model truly needs both state and action, or whether it can solve the benchmark by mostly learning an action lookup table.

Recommended next experiment:

PyBullet v0 ablation:
  full state + action
  state-only
  action-only
  no-action / zero-action

If action-only performs poorly and full state+action remains high, then PyBullet v0 is already a meaningful state-action grounding benchmark.

If action-only performs well, PyBullet v1 should introduce state-dependent dynamics such as walls, obstacles, friction changes, or collisions.
